# Bot Terboo

مساعد ذكي على واتساب (Baileys Multi-Device) بنواة ذكاء واحدة، وفهم حقيقي
للصور والصوت والفيديو والمستندات، ومهام خلفية، و**منصة ويب رفيقة**
(Bot Terboo Web). يعمل بنظام ES Modules ويتطلّب Node.js `>= 22`.

> ملاحظة دقّة: الواجهة تدعم **العربية والإنجليزية** (محرّك اللغات
> `terboo-localization.js` يحمّل `ar` و`en` فقط). أوصاف الإسبانية في
> `package.json` سابقة ولا يدعمها المحرّك حالياً.

## التشغيل

```bash
npm ci                      # اعتماديات البوت
cp config.example.js config.js   # ثم املأ أرقام المالك والمفاتيح
npm start                   # البوت (والموقع إن فُعّل)
```

### تشغيل منصة الويب

الموقع يُستضاف **داخل عملية البوت** (لا عملية ثانية، لا كاتب ثانٍ على قاعدة
البيانات). معطَّل افتراضياً.

```bash
npm run web:install         # اعتماديات الواجهة (قفل مستقل)
npm run web:build           # يبني web/dist
# في config.js: website.enabled = true
npm start
```

| الأمر | الغرض |
|---|---|
| `npm start` / `npm run dev` | البوت + الموقع |
| `npm run web:dev` | واجهة Vite على 5173 توكّل /api إلى منفذ البوت |
| `npm run web:build` | بناء الواجهة |
| `npm run web:typecheck` | فحص أنواع TypeScript |
| `npm test` | اختبارات البوت + audit:strict + lint |
| `npm run test:web` | اختبارات الموقع الأربعة |

التفاصيل: `docs/web-platform/DEPLOYMENT.md`.

## منصة الويب — المبادئ

- **واجهة إضافية لا backend ثانٍ:** لا تعيد تنفيذ الذكاء ولا الصلاحيات ولا
  قاعدة البيانات. تستعمل نفس المكوّنات عبر طبقة خدمات ومحوّلات.
- **مصدر حقيقة واحد:** المستخدمون والأدوار والحظر من مصادر البوت الحقيقية،
  يُقرآن في كل طلب لا عند الدخول.
- **صدق:** كل زر يعمل فعلاً أو يُعطَّل بسبب مفهوم. لا نجاح وهمي ولا HTTPS
  مزعوم بلا شهادة. أوامر واتساب تُعرض كمرجع لا كأزرار تشغيل.
- **أمان:** دخول بإثبات ملكية رقم عبر مقبس البوت، جلسات كوكي HttpOnly، CSRF،
  منع تزوير الدور و IDOR و SSRF، رفع بفحص النوع الحقيقي، لا أسرار في الواجهة.

راجع `docs/web-platform/00_EXECUTIVE_AUDIT.md` للتفاصيل الكاملة.

## الاختبار

```bash
npm run test:syntax     # فحص نحوي + رسم الاستيراد
npm run test:local      # كل الاختبارات المحلية
npm run audit:strict    # تدقيق الهوية/الترجمة/التصميم (يجب أن يكون صفراً)
npm run lint
```

اختبارات الموقع: `web-auth-otp` · `web-api-integration` ·
`web-static-and-assets` · `web-domain-cta`.
