# 02 — رسم الاستيراد ونقاط الدخول

> النسخة الآلية الكاملة في `02_IMPORT_CALL_GRAPH.json`. هذا الملخّص يفسّرها.

## الأرقام

| | القيمة |
|---|---|
| وحدات ESM مفحوصة | 1384 |
| لم تُستورَد ساكناً | 1067 |
| منها تُحمَّل ديناميكياً (plugins/tools/tests بالمسار) | 1004 |
| **بلا استيراد ساكن وليست ديناميكية** | **63** |
| استيرادات مفقودة (ملف هدف غير موجود) | 0 |

## نقطة الدخول

`index.js` ← يستورد النواة والاتصال والمعالج والإضافات والمجدولات، ثم
(جديد) `startWebServer()` من `src/web/index.js`. رسم الاستدعاء الكامل من
`index.js` في JSON.

## لماذا 1004 وحدة «لم تُستورَد ساكناً» ليست ميتة

الإضافات تُحمَّل **ديناميكياً بالمسار** عبر `loadPlugins()` (قاعدة المحمّل:
`import(pathToFileURL(file))`)، فغياب `import` ساكن لها متوقّع ولا يعني موتها.
الاختبارات وأدوات `tools/` كذلك تُشغَّل بالمسار. المولّد يميّزها
(`dynamicallyLoaded: true`) فلا تُحسب أخطاءً.

## الـ63 وحدة بلا استيراد ساكن وليست ديناميكية

كلها نقاط دخول مشروعة لا كود ميت:

| المجموعة | عدد | لماذا ليست ميتة |
|---|---|---|
| `src/lib/terboo-arcade/games/*.js` | ~45 | كل لعبة `export default defineGame(...)` ويُحمّلها `loadArcade()` بالمسار من مجلد `games/` |
| `config.example.js` · `eslint.config.js` | 2 | قالب وإعداد أدوات، لا يُستوردان في التشغيل |
| ملفات أخرى | البقية | نقاط دخول أدوات/اختبارات تُشغَّل بالمسار |

**لا كود ميت مؤكَّد** في هذه القائمة؛ كلها إمّا نقطة دخول أو محمَّلة بآلية
لا يرصدها تتبّع الاستيراد الساكن. (راجع §2.2 في `00_EXECUTIVE_AUDIT.md`.)

## وحدات الموقع الجديدة في الرسم

`src/web/index.js` مستورَد ساكناً من `index.js`. بقيّة `src/web/**` مستورَدة
من `src/web/index.js` و`http/routes/index.js` (بعضها ديناميكي متأخّر —
`connection.js`، خدمات المسارات — لتفادي الأثر الجانبي لاستيراد المقبس
وقت تحميل الوحدة). لا استيراد مفقود.
