# 10 — مصفوفة قدرات الويب

ثلاث حالات لكل قدرة: **ويب** (تعمل من الموقع) · **محوّل/إعداد**
(تعمل بشرط مزوّد أو إعداد) · **واتساب فقط** (تحتاج رسالة/مقبساً ولا تمرّ عبر HTTP).

## الذكاء والأدوات

| القدرة | الحالة | المستوى | الشرط / السبب |
|---|---|---|---|
| محادثة ذكاء | ✅ ويب | user | مزوّد واحد مهيَّأ على الأقل |
| فهم صورة | ⚙ محوّل | user | مزوّد رؤية (GPTVision/GeminiAPI) — وإلا رفض صريح |
| OCR · وصف | ✅ ويب | user | أداة محلية `image.ocr`/`image.describe` |
| تفريغ صوت/فيديو | ⚙ محوّل | user | Whisper حين يتوفّر مفتاح |
| TTS | ✅ ويب | user | `audio.tts` محلي |
| تحميل من رابط (63 scraper) | ✅ ويب | user/premium | حسب صحة المزوّد ونوع المدخل |
| تحويل/فحص مستند | ✅ ويب | user | `document.*` · `file.inspect` محلية |
| توليد/تعديل صورة | ⚙ محوّل | user | scraper خارجي (`txt2img2`/`img2img`) |
| `group.members` | 💬 واتساب فقط | user | تحتاج سياق مجموعة حيّة |

## الحساب والمهام

| القدرة | الحالة | المستوى |
|---|---|---|
| الملف · اللغة · التفضيلات | ✅ ويب | user |
| الرصيد/الطاقة/XP (عرض) | ✅ ويب | user — عرض فقط، لا تعديل من الويب |
| الجلسات (عرض/إلغاء) | ✅ ويب | user |
| ذاكرة الذكاء (عرض/نسيان) | ✅ ويب | user — بتأكيد |
| المهام (عرض/إلغاء) | ✅ ويب | user — ملكية |
| الملفات الناتجة (تنزيل/حذف) | ✅ ويب | user — ملكية |
| الشراء/المتجر/الدفع | ❌ غير مُفعَّل | — لا تنفيذ دفع آمن مراجَع ⇒ لا checkout وهمي |

## الألعاب

| القدرة | الحالة | الشرط |
|---|---|---|
| قائمة الألعاب | ✅ ويب | محرّك الأركيد |
| لعب فردي / ضد الكمبيوتر | ✅ ويب | اللعبة تدعم الخاص |
| كل حركة ونتيجة | ✅ ويب | **تُحتسب على الخادم** — العميل يعرض فقط |
| ألعاب المجموعة | 💬 واتساب فقط | `supportsPrivate = false` |

## المجموعات

| القدرة | الحالة | الشرط |
|---|---|---|
| قائمة مجموعاتي | ⚙ محوّل | مقبس واتساب متصل |
| قائمة الأعضاء | ⚙ محوّل | عضوية مُثبتة + مقبس |
| طرد/ترقية/تنزيل | ⚙ محوّل | مشرف + البوت مشرف + مقبس + تأكيد للجماعي |
| إرسال/بث | 💬 واتساب فقط | تحتاج بناء رسالة |

## البوتات الفرعية

| القدرة | الحالة | السبب |
|---|---|---|
| عرض بوتاتي وحالتها | ✅ ويب | ملكية `ownerJid` |
| إنشاء/اقتران | 💬 واتساب فقط | رمز الاقتران يمنح تحكّماً كاملاً ويُسلَّم خاصاً على واتساب |

## لوحة المالك

| القدرة | الحالة | المستوى |
|---|---|---|
| نظرة عامة · حالة · صحة | ✅ ويب | owner |
| المستخدمون · بحث · حظر/رفع | ✅ ويب | owner — بتأكيد وتدقيق |
| الوظائف · المزوّدات · التدقيق | ✅ ويب | owner |
| الدومين · التحقق · حالة TLS | ✅ ويب | owner |
| إصدار TLS | ❌ خارج العملية | يُرفض بسبب صريح — reverse proxy/ACME |
| shell · eval · قراءة ملفات/أسرار | ❌ ممنوع | غير معروض إطلاقاً |

## السحابة/VPS/Panel/SSH

| القدرة | الحالة | السبب |
|---|---|---|
| لوحة VPS/Pterodactyl/Linode/DO | ❌ لم تُبنَ | المجلدات غير موجودة في الشجرة · المخازن فارغة — لا يُبنى UI لميزة غير مُثبتة |
| قدرات SSH محدّدة (owner) | ⚙ ممكن مستقبلاً | `terboo-ssh*` موجودة لكن لم تُعرض للويب في هذا العمل |

## قانون المصفوفة

- **لا قدرة تُعرض كعاملة وهي لا تعمل.** كل زر معطَّل يحمل سببه.
- **لا نجاح وهمي:** الألعاب والمجموعات والمهام تُعيد ما أثبته المحرّك.
- **القناة صريحة:** أوامر واتساب `webRunnable: false` دائماً.
